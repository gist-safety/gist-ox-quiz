# 연구실 안전 OX 퀴즈 (Lab Safety OX Quiz)

GIST 연구실 안전관리 OX 퀴즈 — 태블릿용 웹앱(PWA)

## 안드로이드 태블릿에 설치
1. 태블릿 **Chrome**에서 이 앱 주소를 엽니다.
2. 오른쪽 위 ⋮ 메뉴 → **앱 설치** (또는 "홈 화면에 추가") → 설치
3. 홈 화면의 **안전 OX퀴즈** 아이콘으로 실행 (전체화면, 오프라인 사용 가능)

## 문제 수정
1. `퀴즈 엑셀 파일/OX문제 선별.xlsx`(쉬움/어려움)와 `퀴즈 엑셀 파일/OX퀴즈_영문번역.xlsx`를 수정
2. `문제변환.bat` 실행 → `questions.js` 갱신
3. `sw.js`의 `VERSION` 숫자를 올리고(예: oxquiz-v2) 다시 업로드
4. 태블릿에서 앱을 한 번 껐다 켜면 새 문제가 반영됩니다

## 설정
`config.js` — 쉬운/어려운 문제 수, 학번 입력 여부, 자동 복귀 시간 등
